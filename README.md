# ICS4U1-Final-CPT - Recreation of Battleship

For our Grade 12 Computer Science CPT, we have decided to recreate the famous Battleship.

## How to Play

- Multiplayer connect using sockets over a local network
- Drag and drop your ships and confirm their position during preparation phase
- Now shoot your missiles on the enemy grid
- Sink all of your opponent's ships before they sink yours

If you have any other questions, you can access our help screen which will provide you with a little interactive help screen.

## Installation/Setup

Ensure that you have Java Development Kit(JDK) installed.

1. Download the Battleship.jar file from our Github Repo.
2. Navigate to the directory: Open the folder where you save the file.
3. **RUN the Jar File**: Execute the following command to start the game:

`java -jar Battleship.jar`
